# UI pass, 24 Sep 2026

First hands-on UI pass of Sortd in the simulator: Dynamic Type AX5, dark mode, Reduce Motion
and adversarial input. Build of branch `ui-pass` at `404f952` (current `main`), Debug, sample
data (`SPEND_DEMO=1`). About 40 minutes of driving. Nothing in the app was changed.

The script could not make the SE: `SORTD_BASE_DEVICE="iPhone SE (3rd generation)" scripts/sim.sh boot`
failed on iOS 27 and on `SORTD_BASE_RUNTIME="iOS 26"` (no stock SE device on either runtime).
I cloned the existing shut-down `Sortd-ux-SE` instead (an SE 3rd gen on iOS 27.0) with
`SORTD_BASE_DEVICE="Sortd-ux-SE"`. Both clones were deleted at the end.

**Modes and how they were set**

- Dynamic Type AX5: `xcrun simctl ui <udid> content_size accessibility-extra-extra-extra-large`
  (this Xcode has the option). Put back to `large` afterwards.
- Dark: `scripts/sim.sh appearance dark`, put back to light.
- Reduce Motion: `xcrun simctl spawn <udid> defaults write com.apple.Accessibility ReduceMotionEnabled -bool true`
  (not the Settings app), put back to false.
- VoiceOver labels: **not read from the UI**. The simulator tool's `inspect` answered
  "'inspect' is not available right now" on every call, so labels were checked in code only.

## Looked fine

- Onboarding, Pro default, every step shown for "spend less / countries / receipts, mix, lost":
  welcome, goals, payment, currency, feeling, budget, check-in, building, plan, cards, card details,
  Apple Pay, Pro. Pick-one pages move on by themselves; Back works.
- Onboarding budget and card-details pages took typed input (99999999 as a budget, letters in the last-4 field) without a crash; the exact values shown were not recorded.
- Monthly Budget sheet: 99999999 in JPY caps at 100000000; deleting to empty greys out Save (budget 0 cannot be saved).
- Add sheet: typing 30 digits keeps only what fits the limit ("12"); swiping the sheet down with an amount typed does not close it.
- Currency change mid-session (AUD to JPY): totals and budget convert (A$1,500 to JP¥185,295); "Update Exchange Rates" shows a spinner.
- Delete All Data: the dialog is clear; Cancel keeps every purchase.
- Search with two spaces shows the full list (treated as empty).
- Back from purchase detail with a swipe from the left edge returns to Activity.
- One quick delete-then-Undo on DoorDash left the row in the list (`.build/ui/activity-undo4-pro-default.png`); it is not clear whether the delete registered.
- Dark mode: Home, Activity, Insights, Settings, paywall, detail (Pro) and Home, Activity, Insights, add sheet (SE): text readable, nothing lost on the background.
- SE default: Home, Activity, Insights, add sheet, detail, paywall, onboarding budget page fit. Pro Max default: Home, Activity, Insights, paywall.
- Welcome at AX5 scrolls down to both "Get Started" and "Bring In Past Spending".
- Reduce Motion: onboarding step change (payment to currency) cross-faded in a screen recording, frames overlap rather than slide. Not compared frame by frame against Reduce Motion off.
- Settings sub-pages at default size: Purchase Sources, Bills & Reminders, Currency, Privacy & Security, Backup & Data. Import sheet (Choose a File / Choose a Screenshot) opens.
- Charts and amounts in code: every `Chart` has `accessibilityLabel` and `accessibilityValue`, and money labels go through `Money.spoken` (13 uses). Code read only.

## Not checked

- **VoiceOver labels in the running app.** `inspect` was never available in this session, so no label was read from the accessibility tree. Code shows `Money.spoken` returns "25.00 Australian dollars" (digits plus the full currency name), not "twenty-five dollars"; how VoiceOver reads that string was not heard.
- **Emoji input.** The simulator tool types ASCII only, and the Paste menu did not appear in the search field. Emoji search and a clean emoji merchant were not tested.
- **Switching tabs during a sync.** No Gmail account is connected in the simulator, so there was no sync to race.
- **Pull-to-refresh twice fast.** Two quick pulls on Activity showed no spinner and no result note. I could not tell whether my swipes started a refresh, so this is not a finding yet.
- **Statement import with a real file** (needs a CSV or PDF in the Files picker).
- Settings pages not opened: Cards & Appearance, Learned Categories, Help & Feedback, About. "Apple Pay Logging" and "Data Controls" as named in the brief are not in this build's Settings list; Apple Pay setup is under Purchase Sources and data controls are "Backup & Data".
- Dark mode on Pro Max; Reduce Motion on Pro Max and SE, and on screens other than onboarding.
- Rotation (the app is portrait only in these runs; not tried).
- Undo timing (finding 2) and the budget change (finding 13) need a careful re-run.
